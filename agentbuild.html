using agents to build agents

You describe it, the agent writes it — then it runs somewhere you can defend

Two halves of one idea. First, a coding agent that turns your design into working agent code — which only works if you give it a proper specification and the right domain knowledge, or it confidently writes against the wrong API. Second, a managed runtime that starts from a locked-down sandbox and lets you add capability on top, so “where does our data go and what can this reach” has an answer before anything ships. Nine sections, eight simulations, every trap the courses warn about.
